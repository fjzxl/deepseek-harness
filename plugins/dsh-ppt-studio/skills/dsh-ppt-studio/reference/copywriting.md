# 文案纪律（写页文字前读）

## 每页一个任务

- 每页回答一个具体问题（页标题即问题或答案）。
- 结论先行：数据页/对比页先给结论，再给论据。
- 章节之间要有叙事逻辑（为什么下一章是这个），框架阶段就想清楚。

## 标题即结论（takeaway）

- 页标题写这页的结论，不写话题名词：✅「Transformer 让模型高效理解长距离关系」❌「Transformer」。
- 页标题不得复述章节名（TITLE_TAKEAWAY 会拦）；把 keyMessage 浓缩进标题。
- 只读全册标题 should 能拼出故事主线——这是检验标题质量的快速方法。

## 叙事衔接（transition）

- 蓝图每页带 fromPrevious（承接上一页/回答上一页的钩子）与 nextHook（给下一页埋钩子）；strictness=strict 时缺失升 warning（NARRATIVE_CHAIN_MISSING），其余档链部分建立时缺口提示 info。
- 阶段 6 用 ppt_scene_check 返回的 storyline 摘要逐页自审：这页是否回答上一页留下的问题？有无突然跳跃？

## 密度控制

- 要点页：≤6 条，每条 ≤2 行（约 ≤28 字）；两条说同一件事就合并（BULLET_BUDGET_EXCEEDED 按密度预算强制）。
- 两栏卡片：每卡 ≤5 行正文。
- 表格：≤8 行 × ≤6 列；单元格 ≤16 字。
- 图表：≤6 个类目；系列 >3 拆分。
- 留白是版面的一部分：宁可拆页，不要挤。

## 图表与表格（数据呈现纪律，0.9.2）

图表的价值在"一眼读出结论"，以下纪律按此排序：

- **数据拥有标记**：柱高/点位/角度必须由数据值决定——不为构图好看挪位置、改数值、截数据。
- **量级柱状图从零基线起**：非零起点会让 2% 差距看起来像 200%，必须截断时在图注明"纵轴自 X 起"。
- **单色深浅优于彩虹**：主系列用主题色全饱和，对比系列同色相约 60% 弱化，点缀色只给关键数据点；趋势正负用色板的红绿语义。
- **直接标签优于图例**：数值标在柱端/点旁（showValues），系列含义写进标题；图例只在多系列且线色难分时保留（单系列图例冗余，校验器会提醒 CHART_LEGEND_REDUNDANT）。
- **同域可比**：并列对比的图表共用同一刻度与类别顺序，除非"差异本身就是要讲的信息"；双轴图只在两系列同域同单位时使用，否则拆成两图。
- **饼/环 ≤6 类**：超了改条形图按值排序，或把 <5% 长尾合并为「其他」（CHART_CATEGORY_CROWD 强制）。
- **标注真拐点**：用文字注出转折原因（"政策变化""产品上线"）；行业均值/目标线用灰色虚线对比。
- 表格：**列宽按语义权重分配，不默认等宽**（标签列窄、内容列宽，用 colWidths 表达）；数字列同单位同精度（"3.2 万"或"32,000"全表一致）；表头用字重加一条细线即可，避免满格网线。

## 语体

- 禁 AI 腔："赋能、抓手、闭环、颗粒度、底层逻辑"堆砌；"首先/其次/最后"机械连接。
- 用短句和主动语态；动词开头写要点（"接入统一网关"而不是"统一网关的接入"）。
- 数字规范：统一单位与精度（"3.2 万"或"32,000"全册一致）；关键数字才上大字号。
- 汇报体听众（领导）：结论+依据+建议行动；教学体听众（学员）：定义+例子+练习；宣讲体听众（公众）：故事+画面+口号。

## 数据与事实（Evidence 层）

- 所有数据必须来自用户材料或用户确认的口径；页面标注来源（11–12pt，textMuted，页底）。
- evidenceLevel=business：数字论断（含图表数据）登记进蓝图 evidence 条目并带 source（EVIDENCE_SOURCE_MISSING 强制）；academic：fact/data 条目全部需来源。
- 没有的数据不放：用"待补充"占位或干脆换成定性描述，绝不编造；内网环境禁止联网取数。
- 图表类型匹配意图：趋势→line，对比→column/bar，构成→pie/doughnut（≤6 类），占比变化→stacked/100% 列。

## 公式排版（技术类 PPT 必读）

- 上下标用 runs 的 `superscript` / `subscript`：`QK^T` → `"QK"` + `{"text":"T","superscript":true}`；`d_k` → `"d"` + `{"text":"k","subscript":true}`；`10000^(2i/d)` → `"10000"` + sup`(2i/d)`。
- **禁止** Unicode `ᵀ ⁱ ⁻`（中文字体普遍缺字形，PowerPoint 渲染成方框）与字面 `x_1` / `QK^T` 记法（显示成代码不像数学）。`² ³`（U+00B2/B3）等常见上标数字可用。
- 主公式行：居中 text 元素、字号比正文大 2-4pt、变量斜体（italic）可选；希腊字母（σ μ γ ε β）与运算符（√ · ≈ → ∂）直接用 Unicode 字符（主流字体有字形）。
- 代码片段（PyTorch 伪码）：保持真实可运行的写法，不要把数学记号（√、^T）混进代码字符串。
